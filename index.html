# RMarkdown

RMarkdown is just Markdwon withR code woven in.

You can do R stuff in the same line as text 6 will show as 6.

you can also do a full-multi-line CHUNK of R stuff:

#```{r}
3 + 3
## [1] 6
#```

setting to control how R chunks appear:

  • eval = TRUE : which actually runs the code; if FALSE, it shows the code but doesn’t run it.
  • echo = TRUE : which shows the code; if FALSE, the code can run withought beeing seen.
  • warnings = FALSE : which will turn off warnings.
  • fig.cap = "figure caption" adds a figure caption.
  • fig.height = 4 example of figure height
  • fig.width = 7 example of figure width
#this will be shown
3 + 3
## [1] 6
## [1] 8
